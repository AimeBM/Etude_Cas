# Etude de Cas : ETAT DES LIEUX DES INEGALITES SOCIALES DANS LE DEVELOPPEMENT DE LA PETITE ENFANCE, cas de la Côte D'Ivoire

PROJET REALISE AVEC MON BINOME : SORO Bakary
SUPERVISE PAR : BAFFO Boris


Données : Les données utilisées dans cette étude sont issues de l'enquête par grappes à indicateurs 
multiples (MICS 5) réalisée en Côte d'Ivoire en 2016.

Calculs d'Indicateurs : réalisés par nous en suivant les definitions dans le Guide pour l’analyse des données statistiques du MICS UNICEF, 2020.

Traitement, Analyse et Modélisation sont réalisés sur STATA
